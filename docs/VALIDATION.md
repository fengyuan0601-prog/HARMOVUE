本版以公开树的实际 1.0.5 应用及 Release 安装包为准。应用 59 个 C# 文件的 PDB 文档校验值与当前源码全部一致；其中 58 个应用文件体沿用 1.0.4，`LibraryViews.cs` 修改关于弹窗的许可和对应源码入口。版本、分发内容和安装器另行调整，见 `source-origin.json`。

## 记录与尚未覆盖

准确安装包摘要、载荷清单、重建记录、设备 PCM 摘要、安装结果和代表性实机截图，放在 [v1.0.5 Release](https://github.com/fengyuan0601-prog/HARMOVUE/releases/tag/v1.0.5) 的 `HARMOVUE-1.0.5-validation.zip`。原生源码包还含完整固定输入索引、许可、工具身份和最终恢复记录。公开摘要移除了个人环境与无关应用画面；来宾为合成测试数据，原始私有机器镜像和账号材料不分发。

本次不是新的实体机重启冷启动测试，也未覆盖所有格式、持续帧率、所有缩放、多屏、HDR 保真、USB/DAC/蓝牙、热拔插和睡眠恢复。WASAPI 输出与实际界面分别验收，均不能证明上述未覆盖项目。安装包尚未代码签名。

README 的原有深浅主题截图来自 1.0.4 在 Windows 上的独立合成库；此前的 CUE/FLAC 边界、其他字幕与格式和人工内置扬声器听音属于历史实测，不能转写为 1.0.5 每项重新验收。历史首播秒数也不为任意机器或新编译提供固定性能承诺。
